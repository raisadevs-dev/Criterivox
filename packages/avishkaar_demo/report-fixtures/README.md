# Report fixtures

These fixtures are presentation-layer examples, not claims that the current runtime has already produced these exact reports.

They demonstrate the intended interchange contract:

1. character reports remain independently addressable;
2. a task report composes references to character/artifact work;
3. the same report sections can be rendered as text or visualization;
4. visualization descriptors identify what they represent and which artifacts they derive from;
5. provenance remains explicit.

The fixture uses synthetic evidence so it can be tested deterministically without turning the demo package into an answer key.
