## Rive architecture learning

Rive is a live animation/runtime system, not a video format.

```text
Character artwork
      ↓
Rive Editor
      ↓
Rig + bones + meshes + animations
      ↓
State Machine / Data Binding
      ↓
dharen.riv
      ↓
Flutter Rive runtime
      ↓
Live GPU rendering
```

A `.riv` contains the character artwork/hierarchy plus runtime animation information such as rigs, animations, state-machine configuration and data bindings.

The intended CRITERIVOX runtime path is:

```text
Python semantic state
        ↓
Runtime transport
        ↓
Dart presentation state
        ↓
Rive Data Binding / ViewModel
        ↓
Dharen state machine
        ↓
Visible animated Dharen
```

The final architecture should avoid building around deprecated Rive `trigger` APIs and should use the current Data Binding/ViewModel approach.

- continuous subtle body motion / breathing
- facial animation and blinking

- controlled transitions
- semantic application states
