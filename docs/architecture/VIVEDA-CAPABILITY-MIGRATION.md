# Viveda First-Class Capability Migration

Viveda owns knowledge consolidation and reusable understanding.

## Verified existing foundation
Set 4 already defines KnowledgeRecord and Set4Runtime.record_knowledge(...), explicitly owned by `viveda`. The runtime requires verification references for VERIFIED or REUSABLE knowledge.

## Implemented here
- Structured knowledge assessment
- Maturity gating
- Verification-reference requirement
- Applicability requirement for reusable knowledge
- Persistence facade over Set 4
- Dedicated Python tests
- Dedicated Dart presentation/workspace/tests
- Navigation and chat routing

## Boundaries
Vivren owns critical reasoning, Medrus owns evidence/experiment, Veridat owns verification, and Manis challenges generalized knowledge. Viveda consolidates what is supported into reusable knowledge while preserving source, evidence, verification, applicability, limitations and uncertainty.

This migration does not claim an independent ontology engine, vector knowledge base, or automatic transfer system where the repository does not provide one.
