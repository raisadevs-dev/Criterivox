# Bodhex First-Class Capability Migration

Bodhex owns insight compilation and governed action preparation.

## Implemented
- Compile recorded analytical outputs into an inspectable insight package.
- Prepare a governed action through the existing operation engine.
- Preserve authorization, precondition, execution, verification, and provenance boundaries.
- Dedicated Python, tests, Dart presentation, and workspace surfaces.

## Boundary
Pramon structures decisions and trade-offs. Bodhex turns an accepted direction into an action representation and controlled operational request. The existing OperationEngine remains shared execution infrastructure.

## Not falsely implemented
Calendar execution is still not implemented because the repository has no production calendar adapter. The capability registry remains explicit about that boundary rather than pretending a UI action performed a real calendar write.
