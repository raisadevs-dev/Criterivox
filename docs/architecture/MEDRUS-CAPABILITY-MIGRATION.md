# Medrus First-Class Capability Migration

Medrus owns evidence acquisition, experimental recording, retention and temporal retrieval.

## Verified existing foundation
The repository already provides S8 EvidenceResearchBureau artifact storage, temporal facts and retrieval, plus Set 4 EvidenceRecord/record_evidence owned by medrus.

## Implemented here
- Character-owned evidence acquisition facade
- Explicit raw evidence state
- Experiment artifact type and recording
- Temporal retrieval facade
- Evidence uncertainty and limitations
- Source/provenance preservation
- Dedicated Python tests
- Dedicated Dart presentation/workspace/tests
- Navigation and chat routing

## Boundaries
Medrus records observations and experiments. Veridat verifies evidence/claims. Tarkis owns hypotheses as a reasoning artifact. Epistre explains/provides lineage. Viveda consolidates supported knowledge.

Experiment records are not verification results, and raw evidence is not treated as established truth.
