# Evidence, Verification and Explanation

Evidence records preserve source, observation, extraction, interpretation, collection method, timestamp, verification state, uncertainty and limitations.

Verification is a separate durable record. Execution or evidence acquisition does not automatically become verification.

Contradictions are first-class records with source pairs, temporal scope, severity and resolution status. UNRESOLVED remains visible.

Vivren's Set 4 explanation model exposes evidence references, assumptions, alternatives, contradictions, uncertainty, decision factors and limitations. It deliberately does not expose hidden model chain-of-thought.

The runtime distinguishes recorded facts, derived state, authorization, execution confirmation, verification confirmation, unknown, not implemented, blocked, failed and partial states.
