# Knowledge Lifecycle

Knowledge is not chat history.

outcome → evidence → verification → knowledge → applicability → adaptation → transfer → future journey

A knowledge record carries source artifacts, evidence references, verification references, context conditions, applicability, limitations, uncertainty and maturity.

Maturity values: OBSERVED, REPORTED, SUPPORTED, VERIFIED, REUSABLE, SUPERSEDED, INVALIDATED.

Verified or reusable knowledge requires verification references. Context adaptation and Anukor transfer are separate records, so a message sent across a boundary is not silently treated as a successful transfer.
