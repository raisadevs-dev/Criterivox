# Character Responsibility Model

The registry remains the source of responsibility semantics. Characters are not independent sources of truth.

| Character | Responsibility surface | Truth boundary |
|---|---|---|
| Syvax | interaction/orchestration | reports runtime records, not invented evidence |
| Dharen | context | reports recorded context and dependencies |
| Sandre | data stewardship | reports stored provenance/data quality |
| Kaelen | build/experimentation | distinguishes experimental from canonical material |
| Anuka | adaptive context | reports recorded adaptation triggers/state |
| Vivren | critical reasoning | structured explanation only, no hidden chain-of-thought |
| Tarkis | hypotheses | hypothesis remains distinct from verified finding |
| Pramon | planning/decision structure | recommendation is not human choice |
| Bodhex | action preparation/execution support | preparation is not execution |
| Medrus | evidence acquisition | observation/acquisition is not verification |
| Epistre | provenance/explanation | lineage does not itself prove truth |
| Veridat | verification | unresolved contradictions remain unresolved |
| Manis | human challenge | cannot make the human decision |
| Viveda | knowledge consolidation | knowledge maturity requires evidence/verification as applicable |
| Anukor | cross-home transfer | message delivery is not transfer success |

Implementation status remains registry-derived. A portrait or chat route never upgrades ARCHITECTURE_DEFINED to CURRENT.
