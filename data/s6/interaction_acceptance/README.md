# Home 01–03 Interaction Acceptance Materials

These are small synthetic, repository-safe materials for manually exercising Criterivox's human-facing workflow.

They are not claimed as external benchmark ground truth and are not training weights.

## Files

- `content_campaign_metrics.csv` — tabular campaign observations for Sandre/Dharen ingestion and contextual reasoning.
- `campaign_context.json` — structured goal, audience, platform and constraints.
- `campaign_brief.md` — natural-language goal/context for Syvax.
- `updated_context.md` — deliberate context shift for Anuka/Dharen diff/replan testing.
- `source_conflict.txt` — deliberate contradiction for context-clash testing.
- `content_artifact.svg` — tiny text-based visual asset for multimodal file identification/preview testing.
- `test_intents.jsonl` — natural-language intent cases with expected routing/interaction outcomes.

Use these with the questions in `docs/S6-HOME01-03-ACCEPTANCE-TEST-PLAYBOOK.md`.

For real-world realism testing, replace these with user-owned/anonymized exports or openly licensed material and preserve provenance/licensing information.
